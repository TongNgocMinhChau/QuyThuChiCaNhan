QUỸ THU CHI CÁ NHÂN – PWA
1. Giải nén thư mục.
2. Chạy bằng máy chủ local (không mở file index.html trực tiếp):
   - VS Code: cài extension Live Server, mở index.html > Open with Live Server.
   - Hoặc chạy: python -m http.server 8000
3. Truy cập http://localhost:8000 (hoặc địa chỉ HTTPS khi triển khai).
4. iPhone: mở trang bằng Safari > Chia sẻ > Thêm vào MH chính.
   Android/Chrome: chọn Cài đặt ứng dụng / Install app.
Tính năng:
- 8 quỹ mẫu; tạo, sửa, xóa quỹ; chọn biểu tượng và màu.
- Ghi nhận khoản thu/chi, ngày, nội dung, danh mục và quỹ.
- Lịch tháng, xem giao dịch theo ngày; báo cáo tháng.
- Giao diện sáng/tối; lưu dữ liệu trên thiết bị bằng localStorage.
Lưu ý: Dữ liệu hiện được lưu trên trình duyệt/thiết bị đang sử dụng, chưa đồng bộ tài khoản hoặc đám mây. Hãy sao lưu dữ liệu thiết bị trước khi xóa dữ liệu trình duyệt.
